    RELEASE POLICY

    Supported browser families

    Chrome, Edge and Firefox are required in the release matrix. Safari remains provisional until its dedicated memory-soak gate passes. Feature detection, not the browser name, decides whether the editor can start.

    Cross-origin isolation is required for the multithreaded engine. If it is missing, the hosting headers must be fixed; Patchy will not silently switch to a weaker runtime.
